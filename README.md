## 💻 Sample Python Program

### Find the Largest Number in a List

```python
numbers = [12, 45, 7, 89, 23, 56]

largest = numbers[0]

for number in numbers:
    if number > largest:
        largest = number

print("Largest number:", largest)
```

**Output:**

```text
Largest number: 89
```
